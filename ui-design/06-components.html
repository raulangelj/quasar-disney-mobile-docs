Decision 6 — Core components

Every token is now locked, so this page is a rendered inventory, not a set of visual alternatives: it is the atom / molecule / organism list the foundation STEP builds from, with each component shown in all its variants and states. Doc 02 §9 lists "both devs need a shared atom the foundation didn't build" as a collision hazard, and names this session as the mitigation — so the point of this page is that the list is complete and that ownership is unambiguous.

Three genuine choices are embedded below, each marked choose: press feedback, loading treatment, and the button API shape. Everything else follows from the reference and the locked tokens.

Ownership rule (the collision mitigation). A component lives in shared/components/ if two or more of {auth, storefront, shell} render it. Otherwise it lives with its feature. That makes the foundation STEP's deliverable a closed list rather than a judgement call, and it means neither dev is ever blocked waiting for the other to publish an atom.

The dashed cyan squares on icon buttons are the 44 pt hit area from decision 4 — drawn to scale, and larger than the visual control in every case. In RN this is hitSlop on the Pressable, not padding on the view, so it does not disturb the tight layout.
